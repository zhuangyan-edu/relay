# skill-cd: 知识脱水、资产分流与联邦回流引擎

作为全系统唯一的知识提纯与资产分流中枢，`skill-cd` 负责将交互中的高价值共识、已验证的技术暗坑与架构决策转化为持久化的高信噪比工程资产。

## 1. 双模流动作业 (Dual-Mode Operations)

### 模式 A：伴随式提炼模式 (Continuous Distillation Mode / 前置与过程)
* **触发方式**：开启深度技术推演、架构研讨或业务梳理前，声明启动 `/cd` 模式（如“带上 /cd 进行研讨”）。
* **作业流程**：
  1. **实时捕捉共识**：在多轮交互行进中，充当“架构记录员与脱水工程师”，随时结构化提炼核心逻辑与权衡依据；
  2. **主动澄清边界**：遇模糊地带主动追问确认，确保结论精准可靠；
  3. **阶段无缝交付**：讨论结束时，直接呈送高信息密度的沉淀草案，待确认后精准落盘。

### 模式 B：收敛式沉淀模式 (Milestone Writeback Mode / 事后与即时)
* **触发方式**：攻克单点技术暗坑、完成阶段交付，或明确输入 `/cd`（口语“沉淀一下”、“持久化”同等生效）。
* **作业流程**：
  1. **资产脱水提纯**：提取已验证的逻辑与解法，剔除过程冗余信息；
  2. **实体类型分流**：严格路由至四大顶层资产与既有容器，精准落盘；
  3. **人机协同落盘**：呈送变更清单，确认后更新至对应物理文件；
  4. **周检台账登记 (Audit Ledger Logging)**：在对应项目的 `.agents/cd-weekly-log.md` 追加单行审计记录（若文件不存在则自动以标准表头初始化），为周检提供确定性线索。

## 2. 五大防腐化分流门禁 (The 5 Anti-Corruption Gates)

任何待沉淀资产必须通过以下五道门禁严格校验：

1. **实体类型精准分流（四大顶层资产各司其职，方便 AI 随时读取与更新）**：
   - **底层思想与协作哲学** ──► 沉淀至全局独立顶层资产 **`~/.agents/PHILOSOPHY.md`**；
   - **系统架构、技术栈选型与重大因果** ──► **直接更新本地 `ARCHITECTURE.md`**（同步更新系统拓扑或在内部 ADR 决策日志追加记录项）；
   - **工作流、流程规则与权限门禁** ──► 直接更新本地 **`AGENTS.md`**；
   - **业务逻辑与产品现状** ──► 自然合并至本地既有 **`CONTEXT.md`**（保持纯净业务事实）；
   - **导航专有名词与物理路径** ──► 独立录入专用字典 **`.agents/proper-nouns.md`**（保护入口与业务文档纯净）；
   - **技术暗坑与实操避坑** ────► 精炼追加至对应模块 **`SKILL.md`** 避坑清单（严禁贴控制台日志）；
   - **已完结重型活动与大体积资料** ──► 提请打包迁出，归档至 **Google Drive (`zhuangyan529898`)** 并在 **`.agents/gdrive-cloud-archive.md`** 登记单行墓碑。
2. **结构合理性校验 (Structural Justification)**：
   - **按需建立，物尽其用**：严格利用既有容器；除明确的模块独立解耦外，绝不臆造新的管理文档或过渡性文件夹。
3. **真实运行验真门禁 (Verification Proof Gate)**：
   - **会话中验证，结果不入库**：技术避坑与代码方案必须由 AI 在当前终端真实跑通、验证无误后才可沉淀；
   - **严禁日志污染**：落盘至 `SKILL.md` 时**仅保留脱水后的【现象 - 根因 - 最小解法/单行命令】**，严禁将终端运行日志粘贴至 Skill 中，杜绝文档臃肿。
4. **渐进聚合与提炼 (Progressive Coalescence)**：
   - 日常微记录以精炼有效为先；
   - 由定期巡检机制（Weekly Custodian）自动将同源碎片经验聚类升级为通用通则，避免信息碎片化。
5. **人机协同确认屏障 (Human Confirmation Gate)**：
   - 涉及核心资产变动、跨模块结构调整时，输出精炼的改动清单与 diff 摘要，获得确认后再行物理落盘。

## 3. 资产流通全闭环机制

### 3.1 专名查表与独立字典 (Dedicated Proper-Noun Registry)
* **独立字典文件**：设立专用的专有名词字典 **`docs/proper-nouns.md`**，统一维护 2~4 字口语化名词与物理路径映射（如 `建科大3D`、`碳核算`）；
* **入口保持纯净**：`AI_START_HERE.md` 仅保留单行入口指引，不承载频繁变更的映射表；
* **缺页自愈 (Page-Fault Self-Healing)**：开发中定位到未登记的核心路径时，顺手写入 `docs/proper-nouns.md`，冷路径永久转为热索引。

* 已完结的重型活动资料整体迁移至 Google Drive 账号 **`zhuangyan529898`**；
* 仓库内仅保留单行墓碑检索指针，保持本地代码仓库轻装敏捷。

### 3.3 母版晋升与联邦回流 (Upstream Federation)
* 在单点项目中沉淀出的通用工具、优秀工作流或高频避坑规则，主动提请晋升至全局跨 AI 母版库（`~/.agents/skills/agent-kit/`）；
